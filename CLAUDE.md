# All-Star Shots

Shot heat maps for the 2026 NBA All-Stars over the 2025-26 season. Pick a player or the whole pool, see a half-court hex map by frequency or by efficiency against the All-Star average, and a zone table underneath. Live at https://shots.jmlr.dev.

**Stack.** Static site: TypeScript + D3 bundled by esbuild, served by an assets-only Cloudflare Worker. Data is pulled once by a Python script (`nba_api`) and committed under `public/data/`. pnpm, Wrangler, Vitest, Playwright, pytest.

**Standing constraint.** A portfolio piece, not a revenue bet. Must not touch the Fantasy IQ season window (opens 2026-10-20).

## Rules

1. **The data is what the NBA reported.** No invented, smoothed, or imported shots. `public/data/` is generated by `scripts/fetch_shots.py` and committed; never hand-edit it.
2. **The Worker never calls the NBA.** Fetching happens on a laptop, output is committed, the Worker serves files.
3. **Math is pure and tested.** Everything under `src/web/lib/` takes data in and returns data out, no DOM, 80% coverage. DOM wiring lives in `src/web/index.ts` and is covered by Playwright.
4. **Constants live in `src/web/config.ts`** (and `ZONES` also in the Python script; the index file is the contract and a test on each side checks it).
5. **Immutable data handling** in code: return new objects, never mutate inputs.
6. **Credit the source.** The footer names NBA.com/stats and states no affiliation. Do not remove it.
